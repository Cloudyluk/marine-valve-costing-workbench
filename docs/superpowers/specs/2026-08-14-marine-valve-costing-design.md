# 船用低温阀门成本核算工作台：设计说明

## 目标

建立一个可公开托管在 GitHub Pages 的静态网页，用于按“产品型号 + 成本版本”查看船用低温阀门的标准成本、成本构成和建议报价，并按生产订单跟踪实际执行成本和标准—实际差异。它与飞书多维表的表结构一致，并保留 CSV 导入接口，方便后续用飞书导出数据更新网页。

## 范围与边界

- 成本对象同时包括一个产品型号的一个成本版本，以及引用该版本的生产订单。
- 生产订单在下达时锁定初始型号成本版本；执行期间允许切换至新的已审核版本，且每一次切换必须保留原版本、新版本、变更原因、变更时间、操作者和标准成本影响金额。
- 初版展示内置示例数据，数据文件可编辑、可审计。
- 支持用户在浏览器内选择 CSV，预览并校验后仅更新当前浏览会话；不会上传或保存数据到服务器。
- 不接入飞书 API、不处理账号登录、审批或实时协同。
- 产出为可部署到 GitHub Pages 的静态站点和飞书多维表建表说明。

## 信息架构

1. 顶部：站点标题、视图切换（型号成本 / 订单执行）、搜索筛选、CSV 导入入口与导出示例数据入口。
2. 型号成本视图：型号版本目录支持按型号、状态及版本搜索；每条记录显示产品参数、完全成本、建议报价和成本更新时间。详情显示成本摘要、成本构成图和四类明细：BOM 材料、工艺与人工、外协与质量、制造费用。
3. 订单执行视图：订单目录按订单号、客户、状态和交付期筛选；详情显示引用的初始/当前型号版本、订单数量、标准成本、实际成本、差异金额/比例和订单毛利。
4. 订单成本明细：实际领料、实际工时、实际外协与质量、实际制造费用；每行可同时对比标准金额、实际金额和差异。
5. 版本变更记录：订单内展示版本切换时间线，记录原版本、新版本、原因、责任人和影响金额；订单即使切换版本，仍可回看原锁定标准。
6. CSV 导入面板：说明应上传的 ZIP/多表 CSV 结构或单一“产品成本版本”/“订单执行”CSV 格式，展示校验结果。初版优先支持两个汇总表的覆盖导入；明细表 CSV 文件接口保留为后续扩展。
7. 飞书落地说明：以网页内的字段映射页面或仓库文档给出关联表、字段类型、关联关系和公式。

## 飞书多维表结构

### 1. 产品成本版本（主表）

主键由“产品型号 + 成本版本”构成。字段包括：产品型号、成本版本、状态、适用开始日期、数量基准、口径、压力等级、低温等级、主体材质、材料成本汇总、直接人工汇总、外协与质量汇总、制造费用汇总、单位完全成本、目标毛利率、建议报价、更新时间、备注。

### 2. BOM材料明细

关联到产品成本版本。字段包括：物料编码、物料名称、类别、材质、单位、定额用量、损耗率、实际用量、含税单价、材料成本、供应商、价格日期、备注。

### 3. 工艺与人工

关联到产品成本版本。字段包括：工序序号、工序名称、工时定额、人工工价、人工成本、设备工时、设备费率、设备成本、备注。

### 4. 外协与质量成本

关联到产品成本版本。字段包括：项目类别、项目名称、计价单位、数量、单价、成本、是否低温/船级社必需、供应商或机构、备注。

### 5. 制造费用分摊

关联到产品成本版本。字段包括：费用项、分配基础、费率、数量、分摊金额、取数期间、备注。

### 6. 成本变更记录

关联到新旧产品成本版本。字段包括：变更编号、变更日期、变更原因、影响类别、成本增减、审批状态、审批人、附件、备注。

### 7. 生产订单（订单主表）

关联到产品成本版本。字段包括：订单号、客户、订单日期、交付日期、产品型号、订单数量、初始成本版本、当前成本版本、版本是否锁定、订单状态、标准单位成本、标准总成本、实际单位成本、实际总成本、成本差异、差异率、销售单价、订单毛利、订单毛利率、负责人、备注。

### 8. 订单实际成本明细

关联到生产订单，记录实际材料、人工、外协质量和制造费用。字段包括：成本类别、来源单据号、物料或工序/项目、标准金额、实际金额、差异金额、差异原因、发生日期、责任部门、备注。

### 9. 订单版本变更记录

关联到生产订单及新旧产品成本版本。字段包括：变更编号、订单号、原成本版本、新成本版本、变更日期、变更原因、标准成本影响金额、操作人、审批状态、备注。

## 计算口径

- 材料成本：BOM 材料明细的材料成本汇总。
- 直接人工：各工序人工成本汇总。
- 外协与质量成本：外协、低温试验、压力试验、无损检测与船级社相关费用汇总。
- 制造费用：按工时、设备机时或产品数量分摊的制造费用汇总。
- 单位完全成本 = 材料成本 + 直接人工 + 外协与质量成本 + 制造费用。
- 建议报价 = 单位完全成本 / (1 - 目标毛利率)。当目标毛利率不在 0 至 1 之间时，网页显示数据校验提示而不计算报价。
- 订单标准总成本 = 订单数量 × 当前成本版本的单位完全成本；初始标准总成本永久保留，用于审计。
- 订单实际总成本 = 订单实际成本明细中实际金额的汇总。
- 订单成本差异 = 订单实际总成本 - 当前标准总成本；同时展示相对初始标准的累计差异。
- 订单毛利 = 订单含税/不含税销售收入（由订单口径统一）- 订单实际总成本。

## 技术方案

- React + Vite 静态站点，TypeScript 与原生 CSS。
- 示例数据和字段映射以本地 TypeScript/JSON 文件维护；所有汇总在浏览器端计算。
- 使用浏览器 File API 读取 CSV；采用固定中文字段名映射，并对必填字段、数值和毛利率做校验。
- GitHub Actions 使用官方 Pages 工作流构建并部署；仓库无需服务器端密钥。

## 交互与错误处理

- 目录记录可点击切换详情；筛选与搜索即时更新记录数。
- CSV 导入前显示所识别列和数据行数；导入失败时指明缺失列或错误行，不覆盖当前示例数据。
- 只接受 UTF-8 CSV；发现无法识别的列时保留提醒，但允许导入已识别字段。
- 空状态、零成本和 0% 毛利率均有明确展示，避免除零或空白误读。

## 验证标准

- 构建成功；每个示例版本的成本构成之和等于完全成本。
- 搜索、状态筛选、版本详情切换、CSV 导入预览及成功/失败状态可在浏览器中操作。
- 桌面和移动视图无横向溢出，核心金额和表头可读。
- 页面以 GitHub Pages 基路径运行正常。
